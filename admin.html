Production Setup Plan

1. Admin authentication: protected admin login with MFA, session management and role-based authorization.
2. Database: customers, inquiries, quotations, orders, payments, projects and audit logs.
3. Customer access: each customer can view only their own orders, quotations and receipts.
4. Razorpay: server creates orders; frontend uses only publishable key; backend verifies payment signatures and webhook events.
5. Privacy: HTTPS, data minimization, access logs, retention policy, backups and consent where applicable.
6. Deployment: keep public services.html separate from a securely hosted admin app; do not rely on secret URLs or client-side hiding.

Recommended flow: Requirements → feasibility → quotation → customer approval → payment → production → testing → delivery.
